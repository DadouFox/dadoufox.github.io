# Portfolio de Damien Gauthier

Bienvenue sur le dépôt de mon portfolio personnel. Ce site présente mon parcours scolaire, mes projets, ainsi que mes compétences en informatique.

## Structure du projet

- **index.html** : Page d'accueil avec une présentation personnelle et mes compétences.
- **cursus.html** : Page détaillant mon parcours scolaire.
- **projects.html** : Page présentant mes projets réalisés.
- **styles.css** : Fichier contenant les styles CSS pour le site.
- **CV Damien_Gauthier.pdf** : Mon CV téléchargeable.
- **images/** : Dossier contenant les images utilisées sur le site.

## Fonctionnalités

- Navigation entre les différentes pages.
- Présentation des compétences en informatique.
- Affichage des projets avec des détails supplémentaires via un bouton "Voir plus"/"Voir moins".
- Téléchargement du CV au format PDF.

## Technologies utilisées

- **HTML5** et **CSS3** : Pour la structure et le style du site.

# Portfolio de Damien Gauthier

## Présentation

Ce site web est un portfolio personnel développé dans le cadre de mes études en BUT Informatique à l'IUT de Clermont-Ferrand. Il met en avant mon parcours scolaire, mes compétences, mes projets et permet de me contacter facilement.

## Structure du projet

- **index.html** : Page d'accueil (présentation, navigation, photo, résumé).
- **pages/skills.html** : Compétences informatiques (SQL, C, C++, C#, Python, HTML/CSS, Shell, XAML).
- **pages/projects.html** : Projets réalisés durant le cursus (SAÉ, projets d'équipe, etc.).
- **pages/cursus.html** : Parcours scolaire (collège, lycée, BUT).
- **pages/contact.html** : Informations de contact (email, téléphone, GitHub, GitLab) et formulaire de contact.
- **styles/** : Dossier contenant les fichiers CSS spécifiques à chaque page.
- **common.css** et **index.css** : Styles globaux et page d'accueil.
- **images/** : Images et icônes utilisées sur le site.
- **CV Damien_Gauthier.pdf** : CV téléchargeable.
- **scripts/** : Scripts JavaScript pour l’interactivité (ex : affichage dynamique des projets).

## Fonctionnalités

- Navigation claire entre toutes les pages via le menu principal.
- Présentation détaillée des compétences informatiques avec logos.
- Affichage des projets par année, avec détails et filtres.
- Présentation du parcours scolaire (collège, lycée, BUT).
- Formulaire de contact fonctionnel et liens directs (email, téléphone, GitHub, GitLab).
- Téléchargement du CV au format PDF.

## Installation et utilisation

1. **Cloner le dépôt**
	```bash
	git clone <url-du-repo>
	```
2. **Ouvrir le dossier dans un navigateur**
	- Ouvrir `index.html` pour accéder au site.
	- Toutes les pages sont statiques, aucune dépendance n’est requise.

## Technologies utilisées

- **HTML5** : Structure des pages
- **CSS3** : Mise en forme et responsive design
- **JavaScript** : Interactivité (scripts/)
